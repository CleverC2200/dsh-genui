# T5 业务展示与计算门禁验收补充

2026-11-12。v8 隔离运行验收通过。本记录补充[原始失败记录](business-presentation.ACCEPTANCE.md)，保留旧结果，不将旧失败改写为通过。

## 范围与改动

本次修复名称/单值短答多报数量、完整组件后重复正文，以及工具卡动作通道。最终组件通过官方公开的 `concludeTurn()` 结束当前轮次，按钮可进入新轮次。没有删除已经输出的正文或隐藏 DOM 来达到验收。

用户另外批准隔离 GEA/Manage 接线与业务计算门禁。Manage 运行有界纯计算，GEA 将真实用户原文来源、当前轮次成功工具结果和最终展示引用绑定；未绑定的数字或状态在发布前拒绝，并保留失败候选。GenUI 消费已准入的值。门禁不证明自由文字中的任意业务含义或公式选择都正确，固定案例仍逐项进行独立语义复核。

## 实际输入与边界

正常业务模型仍为 `gea-analysis` 的 `2102773062849409026`，没有改模型或换业务 persona。原 3750 字业务规则作为系统提示前缀逐字保留，实际系统提示为 6257 字，接入当前原生 GenUI 与 `business_values` 工具说明。原 41 项工具定义的值和顺序保留，另有两项 GenUI 工具和一项纯计算工具。

所有案例为合成数据。恢复分页输入原文已明确给出 200 箱，直接引用不是新计算；它只覆盖已读两行，不能成为全部 100 笔的总量。本轮 v8 没有生产查询、业务写入、官方 Core 修改或正式客户端启动，只启动独立 Electron、私有 app 和 profile，验收结束后已关闭本次进程；既有用户数据与失败证据保留。

执行边界只允许沙箱计算、纯计算工具、缓存 GenUI Skill 与两个 GenUI 工具。其他真实工具定义仍可见，原处理器在执行前被拒绝；预检实际验证普通工具、调度路径、其他 Skill 和非法计算参数均被拒绝。
